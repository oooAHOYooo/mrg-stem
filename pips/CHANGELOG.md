# Changelog - Pips

## 2026-03-25
### UI Panel Collapse Toggles
- **Min/Max Panels**: HUD, District Intel, and District Dock panels now have +/− toggle buttons to collapse and expand, with smooth CSS transitions.

### Gamification & Minecraft Features
- **Minecraft Hotbar**: Added an 8-slot hotbar with support for items and keyboard shortcuts (1-8).
- **Hat System**: Implemented a 3D accessory system for Pips. Hats (Wizard, Hard Hat, Beret, Crown) now change the agent's LLM model, provider, and personality.
- **Pointer Lock Locomotion**: Switched to true FPS-style camera. Click to lock cursor, Esc to release.
- **Sprint & Head Bob**: Authenticated movement speeds (4.3m/s walk, 5.6m/s sprint) with view-bobbing effects.
- **Crosshair**: Added a central UI crosshair for aiming.
- **Pokeball Mechanics**: Added physics-based projectiles to capture Fairies and Wild Pips.
- **Wild Pips & Evolution**: Ghostly pips spawn in the wild. Capturing them adds them to the Glade. Pips now earn XP from chat and "evolve" (upgrade models) at Level 4.
- **Balloon Launching**: In Playful Mode, Right-Click launches crates into space with balloons; Left-Click shoots them down.
- **Forge Glade Default**: The experience now begins in the industrial Forge Glade.
- **Draggable UI**: All HUD panels and chat windows are now draggable and save their positions to localStorage.
