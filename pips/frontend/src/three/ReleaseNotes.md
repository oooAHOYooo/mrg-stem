# Pips Lab Release Notes

## [v1.1.0] - 2026-04-23
### Added
- **Agent Communication**: Pips can now "talk" with floating speech bubbles.
- **Prompt Notes**: Added the ability to visualize "best prompts" as floating sticky notes in the 3D world.
- **Conversation Logs**: Persistent history of agent interactions stored in the browser's local storage.
- **Copy Functionality**: Ability to copy conversation logs for sharing.
- **Agent Refactor**: Moved Pip logic into a more robust state management system.

### Changed
- Refactored `pips.js` to support dynamic text rendering and note placement.
- Enhanced Eye Tracking to look at notes and the player during conversation.

### Improved
- Render performance for many pips.
- Interaction distance for talking to agents.
