# 🎨 Guide: Displaying Student Tinkercad Work with Embeds

## Quick Start - 3 Simple Steps

### Step 1: Get Student Share Links
1. Student creates design in Tinkercad (using class code: **TBIBWWFLY**)
2. Student clicks **"Share"** button (top right)
3. Student sets privacy to **"Only people with the link"** or **"Public"**
4. Student copies the share link (looks like: `https://www.tinkercad.com/things/ABC123...`)
5. Student shares link with you (or you access it through classroom dashboard)

### Step 2: Add to Portfolio Admin
1. Go to **`tinkercad-portfolio-admin.html`** (or click "Portfolio Manager" in sidebar)
2. Click **"➕ Add New Project"** button
3. Fill in the form:
   - **Project Title**: Name of the design
   - **Student Name**: Who created it
   - **Class**: Optional (e.g., "5A")
   - **Tinkercad URL**: Paste the share link from Step 1
   - **Description**: What they created, what they learned
4. Click **"Add Project"**
5. The 3D viewer will appear automatically!

### Step 3: View & Organize
- **Drag and drop** project cards to reorder
- **Edit** projects by clicking ✏️
- **Delete** projects by clicking 🗑️
- Projects automatically show interactive 3D viewers

## 📋 Detailed Step-by-Step

### Getting Share Links from Students

#### Option A: Students Share Links Directly
1. Student logs into Tinkercad with class code: **TBIBWWFLY**
2. Student opens their design
3. Student clicks **"Share"** button (top right corner)
4. Student changes privacy to **"Only people with the link"** (or "Public" if available)
5. Student copies the link
6. Student sends you the link (email, Google Classroom, etc.)

#### Option B: Access Through Classroom Dashboard
1. You log into your Tinkercad account
2. Go to **Dashboard** → **Classes**
3. Click on your class
4. See all student designs
5. Click on a design to open it
6. Click **"Share"** button
7. Set to **"Only people with the link"** or **"Public"**
8. Copy the share link

### Adding Projects to Portfolio

1. **Open Portfolio Admin**
   - Navigate to `tinkercad-portfolio-admin.html`
   - Or use sidebar link: "📁 Portfolio Manager"

2. **Add Project**
   - Click **"➕ Add New Project"**
   - Or paste Tinkercad URLs into the drop zone

3. **Fill Form**
   ```
   Project Title: "3D House Design"
   Student Name: "Alex"
   Class: "5A"
   Tinkercad URL: https://www.tinkercad.com/things/ABC123...
   Description: "Created a house with windows and doors"
   ```

4. **Save**
   - Click "Add Project"
   - 3D viewer appears automatically!

### Organizing Projects

- **Reorder**: Drag and drop project cards
- **Edit**: Click ✏️ button on any card
- **Delete**: Click 🗑️ button (with confirmation)
- **Preview**: 3D viewer shows on each card

## 🎯 Best Practices

### For Teachers:
1. **Collect links weekly** - Set aside time to gather student share links
2. **Use Google Forms** - Have students submit links via form
3. **Batch add** - Paste multiple URLs at once in the drop zone
4. **Organize by class** - Use the "Class" field to group projects
5. **Add descriptions** - Help students reflect on what they learned

### For Students:
1. **Make designs shareable** - Set to "Only people with the link" minimum
2. **Name designs clearly** - Use descriptive titles
3. **Share links promptly** - Send links when design is ready
4. **Update designs** - Share new links if they update their work

## 🔧 Troubleshooting

### "3D viewer not showing"
- ✅ Check that design is set to "Only people with the link" or "Public"
- ✅ Verify the URL is correct (should include `/things/`)
- ✅ Try opening the link in a new tab to test
- ✅ Check browser console for errors

### "Can't find Share button"
- Look in top right corner of Tinkercad editor
- Check for three-dot menu (⋮)
- Try right-clicking on design thumbnail
- Make sure you're logged into correct account

### "Embed not working"
- Try "Only people with the link" instead of "Public"
- Verify the URL format is correct
- Test the embed URL directly: `https://www.tinkercad.com/embed/[PROJECT_ID]`
- Check if classroom has sharing restrictions
